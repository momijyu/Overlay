# Overlay 発表用メモ

## アプリの概要

Overlayは、講義資料や演習問題などのPDFに、ブラウザ上で直接書き込みを重ねられるノートアプリです。配布された資料を読みながら補足を書き、後から必要なページを見返したい大学生を主な利用者として想定しています。

## 主な機能

- PDF上へのペン・マーカーでの書き込み、消しゴム、テキスト、付箋、図形や画像の追加。
- 付箋の一覧から該当するノート・ページへの移動。
- ページの追加・削除、白紙のテンプレート、ページ一覧や見開き表示。
- 復習に使う目隠しテープ。PDFの書き出しには含めません。
- ノートやフォルダの一覧・整理と、編集内容の自動保存。
- 書き込みを重ねたPDFの書き出しと、再編集用バックアップの保存・読み込み。

## データの保存

ノートはブラウザ内のIndexedDBに保存します。Google Driveと連携すると、ノートやフォルダをDriveにも保存でき、別の端末から利用できます。Driveへの反映には通信時間がかかります。リアルタイムの共同編集には対応していません。

ブラウザのサイトデータを削除すると、そのブラウザ内のデータも削除されます。PDF書き出しは閲覧・共有用で、編集を続けるためのバックアップとは別です。

Google連携は本番環境へ切り替え済みですが、Googleの確認状況やテストユーザー以外による利用は別途確認が必要です。

## 使用技術

- Next.js、React、TypeScript：アプリケーションと画面。
- PDF.js：PDFの表示。
- pdf-lib：書き込みを含むPDFの書き出し。
- IndexedDB：ブラウザ内のノート保存。
- Google Drive API：利用者のGoogle Driveへの保存。
- Vercel：Webアプリの公開。

## 実演の流れの例

1. 講義資料のPDFを開く。
2. ペンで書き込み、付箋に短いメモを残す。
3. 付箋一覧から、メモしたページに移動する。
4. 書き込みを含むPDFを書き出す。

必要に応じて、ノートの自動保存やGoogle Drive連携も紹介します。
