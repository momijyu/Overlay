# テキストボックスと付箋

2026年10月20日の追加実装。第4回の範囲。デザインの仕上げは第4回の最後に行う。

## 操作

### テキストボックス

1. 「テキスト」を選び、PDF右上の「テキストを追加」を押すと空の入力欄が出る。PDF上の空白をクリックして、その位置へ置くこともできる。
2. 入力欄の外を押すか「完了」、Ctrl+Enter（MacではCommand+Enter）で確定・自動保存する。Enterだけなら改行する。Escapeまたは「キャンセル」で草稿を取り消す。
3. 既存の文章をクリックすると、その場で再編集できる。選択枠のドラッグで移動する。
4. 入力欄の「文字サイズ」のスライダーを小〜大へ動かすと、その場で文字と箱の大きさが変わる。必要なら右の数値欄でも8〜48の整数で指定できる。初期値は14。
5. 箱の幅・高さは文字に合わせて自動調整する。長い行だけページ幅で折り返す。以前の手動リサイズのハンドルは廃止した。サイズの調整は文章と一緒に確定するまで保存しない。
6. 移動は指を離して確定・自動保存する。移動中断では保存しない。選択中または入力欄の「削除」で削除できる。
7. 入力欄の「文字色」で色を選ぶ。付箋には「背景色」も表示する。色はプレビューし、文章・サイズとまとめて確定・自動保存する。キャンセルは変更を残さない。

配置時のpointerdownで開いた入力欄を、その直後の同じclickで空のまま閉じないようにした。既定のフォーカス移動も止め、新しい入力欄へフォーカスを残す。選択中の項目がある時に、空白クリックが選択解除だけで終わる処理も削除した。実ブラウザでの操作確認は未完了。

### 付箋

「付箋」を選び、「付箋を追加」ボタンかPDF上の空白クリックで設置する。別の入力画面は開かず、淡い背景の付箋内へ直接入力する。テキストと同じ小〜大スライダー・数値指定で文字サイズを変え、箱も文章に合わせて自動調整する。外側クリック・完了・Ctrl/Command+Enterで確定し、Escape・キャンセルで取り消す。既存の文章はクリックで編集、枠のドラッグで移動、入力欄や選択中の「削除」で削除できる。

どちらも、ペン・マーカーの描画と同様に、追加・文章編集・文字サイズ変更・色変更・移動・削除を「元に戻す」「やり直す」で1操作ずつ戻せる。文章・文字サイズ・文字色・背景色は1回の入力開始から確定までを1操作とし、1文字・スライダーの1刻み・色のプレビューごとには履歴を増やさない。

両方のメモをどちらの道具からも編集できる。テキストボックスは背景なし、付箋は仮の淡い背景を付けて文章を常時表示する。PDF出力でもその文章と背景を表示する。付箋の折り畳み・付箋一覧はまだ作っていない。消しゴムはペンの線だけを対象とし、文章は消さない。

## 保存タイミング

PDFを開いただけでは保存しない。最初の描画完了、またはテキスト・付箋の入力確定から保存する。

文章入力中の草稿は未確定で保存しない。「キャンセル」は元の内容を維持し、新規項目なら何も追加しない。空の新規ボックスから離れても追加しない。既存の文章を空にした場合はエラーとし、削除ボタンとは区別する。

テキストは外側のクリックをページ切り替え・道具切り替え・ノート読み込み・PDF出力より先に処理し、確定した最新の文章と文字サイズを渡す。サイズ操作欄は入力欄の一部として扱い、スライダーや数値欄へ移っても文章を確定しない。ページに収まらない文章や未対応文字がある場合は切り替えを止め、入力を残す。大きくするとページを超える場合は変更前の文字サイズを維持してエラーを表示する。IME変換中は誤確定・サイズ変更を防ぐ。倍率や幅の再描画だけでは入力欄を作り直さない。非表示・pagehide時にも確定を試みるが、変換中・不正な草稿・OSによる即時終了の保存までは保証しない。移動中はプレビューだけで、指を離すまで履歴・保存へ渡さない。

確定した文章・位置と線は同じ保存処理で扱い、保存中の追記は最新の状態を続けて保存する。失敗時は画面に内容を残し、「保存を再試行」で再実行する。読み込み・削除の失敗でも編集中のノートを残す。

## データ

元PDFのBlobは既存の`pdfs`ストアへ保存する。既存の`notes`ストアのノートに、ページごとの`textsByPage`を追加した。新しいストア・DBバージョンの変更・外部DBは追加していない。

各項目は`id`、`kind`（text / sticky）、`text`、`x`・`y`、`width`、`fontSize`を持つ。新しいテキスト・付箋は`autoSize: true`を保存し、文章と文字サイズから幅・高さを計算する。空欄や短文でも入力しやすいよう幅は最低80基準単位とし、ページ幅を上限にする。

旧データの任意の`height`・幅・文字サイズは、開いただけでは書き換えない。文章や文字サイズを変えた時点で自動調整へ切り替える。付箋も種類はstickyのまま、背景・保存先・IDを維持する。新しいDB形式やマイグレーションは不要。

2026年10月20日の続く指示で、任意の`color`（文字色）と付箋専用の`backgroundColor`（背景色）を追加した。6桁の16進色だけを受け付ける。未指定は従来の文字色`#111827`・付箋背景`#fff3b0`で表示し、読み込みだけで値を追加しない。色だけを変える場合は旧幅・高さと自動サイズ設定を保持する。保存・再読込・移動・Undo / Redo・PDF出力のすべてで選んだ色を維持する。

位置・幅・旧データの高さはページの縦横に対する0〜1の値で、ズーム時も位置関係を維持する。長い行は自動で折り返す。ページに収まらない文章は拒否して入力を残す。

テキストのない旧ノートは空のメモ一覧として読み込む。読み込み・保存時に種類・重複ID・文章・座標・幅・文字サイズを検証する。線だけを扱う旧経路から更新するときは、保存済みの文章を消さない。ノートの整理・名前・元ファイル名はそのまま維持する。

| `components/TextBoxEditor.tsx` | 両種類の直接入力と文字サイズ・文字色・付箋背景色の草稿。外側クリック・完了時にまとめて確定。キャンセル、IME・エラー時の入力保持 |

## 日本語PDF出力

`@pdf-lib/fontkit`とNoto Sans JP Regularを使用する。使用箇所はテキスト表示とPDF出力だけで、基本UIのフォントは変えない。フォントは同じサイトから取得し、PDFやメモは外部へ送らない。初回取得は約4.3MiBで、ペンだけのノートでは不要。出典・ライセンスは[フォント資料](../public/fonts/README.md)に記載した。

画面とPDFで同じフォントの文字幅・行の高さ・改行位置を使用する。文章を画像に変換せず、PDF上でも選択・検索できる文字として出す。CFFの部分埋め込みでは字形の問題が出たため、今回はフォント全体をPDF内に1つ埋め込み、全ページで共有する。出力の容量はフォント分だけ増える。

フォントが持たない文字（例：一部の絵文字）は黙って消さず、適用時・PDF出力時にエラーを表示する。保存済みデータにそのような文字があっても、入力画面から編集・削除して修正できる。元PDFの文字を編集する機能ではない。

## 今回の制限と次の確認

- 1項目2000文字。文字色・付箋背景色は変更できる。付箋の折り畳み・一覧は未実装。箱の手動リサイズは行わない。
- 不正な草稿・変換中の文章は、閉じた後の保持を保証しない。確定・保存済みの内容と区別する。
- 履歴は直近100操作で、ノート切り替え・再読み込み後には持ち越さない。
- 出力PDFは閲覧・共有用で、Overlayの元データ・階層を復元するバックアップではない。
- デザインと今回変更後のChrome・公開URLの確認はこれから行う。Safari・iPadの互換性は暫定保留。v1.0.0の完成とは扱わない。
