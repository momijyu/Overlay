# 目隠しテープ

2026年11月14日追加。回答や用語を覆い、タップして確認する復習用の表示機能。利用者指定により、全体・指定ページのPDFにはテープを出力しない。元PDFの文字・画像を削除する墨消し機能ではない。

## 操作

1. 道具の「目隠しテープ」を選び、PDF上でドラッグして配置する。「テープを追加」からも置ける。
2. テープをドラッグして移動し、選択中の右下の丸をドラッグして幅・高さを変える。ページ外へはみ出さないよう制限する。
3. テープをタップして下の内容を表示・非表示にする。「ページを動かす」道具でもタップして切り替えられる。「すべて隠す」は表示中ページのテープを再び隠す。
4. 選択後に「テープ削除」。ページ操作の書き込み一括削除でも「目隠しテープ」を選べる。

スマホでは道具の設定パネルから操作する。二本指はテープの編集を取り消してPDFの拡縮へ切り替える。見開きでは押した側のページを編集する。テープは画像・ペン・文章等の前面に表示する。

## 保存と履歴

配置・移動・サイズ変更・削除の完了を1操作として既存のUndo／Redo・自動保存へ渡す。道具・倍率・資料の切り替え、二本指への移行、ポインター中断では未確定の矩形を保存しない。保存失敗時の再試行・Driveの認可／競合／未送信保護は既存方式を維持する。

表示・非表示の切り替えは画面内だけで、保存・履歴・Drive通信を発生させない。ページの開き直し・再読込・テープの編集後は隠した状態へ戻る。表示切替だけでは未保存の新しいPDFをノートへ登録しない。

固定ページIDごとの`tapesByPage`へ、ID・割合座標・幅・高さだけを保存する。安全上限は1ノート1,000枚。IndexedDBは版8のまま、テープを含む編集用バックアップ／Drive本文は形式版6を使用する。旧版1〜5はテープなしで開き、旧アプリは未知の版6を拒否する。編集用バックアップからは再編集可能なテープを復元する。PDF出力はテープの表示状態によらず元の内容と通常の書き込みを出力する。

投げ縄・コピー／貼り付けの対象へは今回追加していない。色の変更・図形以外のテープ形状は拡張候補。

## 実装箇所

- `maskTapes.ts`：矩形・ID・件数の検証とページ内の配置計算。
- `TapeLayer.tsx`：配置・移動・拡縮・表示切替・操作中断。
- `PdfPage.tsx`／`PdfWorkspace.tsx`：表示・道具・編集履歴と自動保存の接続。
- `strokeHistory.ts`：テープ編集・ページ削除・種類別一括削除のUndo／Redo。
- `localNotes.ts`、`noteBackupData.ts`／`noteBackupFile.ts`、Drive関連：保存・復元・形式版6・内容ハッシュとキャッシュ。

実機・実Drive・公開環境の確認状況は[第7回確認記録](phase7-checks.md)へ記録する。
