# Overlay 現在の引き継ぎ

2026年11月16日時点の要点。会話や過去の記録より新しいユーザーの指示を優先する。

## プロジェクト

Overlayは、PDFに手書き、テキスト、付箋、画像などを重ねて使うブラウザアプリ。ローカルのIndexedDBと、任意のGoogle Drive連携を使う。未送信の編集や既存データを失わないことを優先する。

## 確認できていること

- ユーザーはスマートフォン・iPadでの使用、Drive同期、保存・書き出しがおおむね動作したと報告している。
- OGP・ファビコンは設定済み。画面の追加改善は必要になった際に別のissueとして扱う。
- Driveの速度は、これ以上の改善が見込めないため現状の仕様として扱う方針。

## 完成に向けた残り

1. Googleアカウント切り替えの確認。別アカウントへ切り替えるとノートを開けない・保存できないという報告があり、ローカルに修正作業が残っている。実際に A → B → A と切り替え、各アカウントの一覧・読み書きと未送信データの保護を確認する。
2. Google OAuthの公開状態を確認する。ユーザーは公開設定を操作済みだが、Googleの確認状況とテストユーザー以外でのDrive接続成功は未確認。
3. 公開済みの紹介・利用規約・プライバシーポリシーと実際の動作が一致しているか、公開前に確認する。
4. 修正後の自動テストと必要な実機確認を行う。ユーザー自身がcommit・pushを行う。

アカウント切り替え関連の変更は未コミットの作業として存在する。既存の変更や実データを消さず、状態を確認してから作業する。テストは検証用ノートを使う。
