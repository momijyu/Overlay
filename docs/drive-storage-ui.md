# Drive保存状態とキャッシュ容量

2026年11月5日のユーザー指定による第5回の追加。既存の自動保存・競合保護を維持する。

## ノート一覧のマーク

| 表示 | 意味 |
| --- | --- |
| 雲なし | この端末にPDFと編集本文がそろっているノート（Driveにも保存済みの場合を含む）、またはブラウザ専用ノート |
| 雲 | この端末にPDFと編集本文がそろっておらず、Driveから取得が必要 |
| 雲と上向き矢印 | ローカルに本文がそろっておらず、Driveの送信・階層変更も待機中 |
| 雲と警告 | ローカルに本文がそろっておらず、保存失敗・競合・別端末の複数版等の確認が必要 |

同日の最新指示で、雲の意味を「Driveへ保存済み」から「この端末への取得が必要」へ変更した。Driveとローカルの両方にあるノートには、送信待ち・警告も含めて雲を付けない。Drive保存の失敗・競合などは既存の自動保存パネルやエラー案内で確認できる。

マークを押す・フォーカスする・マウスを重ねると短い状態を確認できる。マークだけを押してもノートを切り替えない。図形と読み上げ用のラベルを付ける。Driveから本文を取得すると雲が消え、キャッシュ整理で端末の本文を外すと再び表示する。PDFか編集本文の片方だけでは、取得済みとは扱わない。

表示用の情報はPDF・編集本文・変更履歴全件を読まず、`driveBindings`・`driveEntities`、小さな階層送信待ちフラグ、`notes`・`pdfs`のキーだけから取得する。同じタブの変更通知と、一覧を開いている間の5秒間隔で更新する。一覧を閉じた間の定期取得はしない。切断時の表示は最後に確認したDriveの情報に基づき、取得には再接続が必要な場合がある。

## 容量設定

ノート一覧の「Drive自動保存 → キャッシュ設定」を開く。

- 初期値：250MB。以前の固定値500MBを置き換える。
- 指定範囲：100〜1,000MBの整数。1MBは1,000,000バイト。
- スライダーと数値入力を同期し、「適用」で保存する。不正な値は保存しない。
- 設定は同じブラウザ・同じサイトURLのIndexedDBに保存する。Googleアカウントや別端末へ同期しない。
- 使用量は記録済みのPDF・編集本文の概算。ブラウザ全体のサイト使用量やDrive使用量とは異なり、ブラウザ内部のオーバーヘッド等は含まない。

設定の保存だけではノートを削除しない。Drive連携の次のキャッシュ整理で新しい上限を参照する。通常は約30秒以内の整理で反映するが、通信停止・ブラウザ休止・認証切れなどで遅れる場合がある。

未使用30分後の整理は維持する。上限を超えた場合は30分以内でも古い再取得可能データから整理する。未送信・保存失敗・使用中・他タブで使用中・ローカル専用データは保護するため、設定値を超えることがある。上限を下げてもDrive本体や一覧・階層は削除しない。容量を小さくすると再取得が増える。

DB版7・Driveのファイル形式・編集可能なバックアップ形式は維持する。新しい設定は既存の`driveSettings`へ追加し、既存本文を書き換えない。

## 実装

- `noteDriveStatus.ts`：保存番号・参照・失敗等から3種類の状態を作る。
- `NotebookDriveBadge.tsx` / `NotebookTree.tsx` / `NotebookSidebar.tsx`：一覧の表示、短い案内、更新監視。
- `PdfWorkspace.tsx`：現在のノートのブラウザ保存中・失敗を一覧へ渡す。
- `driveCacheSettings.ts`：設定値の検証・読み込み・保存。
- `driveLibraryCache.ts`：設定した上限による整理と概算使用量。
- `DriveCacheSettings.tsx` / `DriveAutosavePanel.tsx`：容量設定の操作画面。
