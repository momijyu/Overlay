# スマホ・タッチ操作の改善

2026年10月21日、第4回のUI改善として追加。スマホでの二本指と描画の衝突、付箋移動、編集領域の狭さへの対応。保存先・元PDF・既存の線やメモのデータ形式は変更しない。

## 操作

- ペン・マーカー・消しゴムは従来どおり一本指で操作する。
- PDF上で二本指になったら、未確定の線・消去・メモ移動を破棄し、指の距離で拡縮、中間位置で移動する。倍率は既存と同じ50〜200%。一本だけ残っても描画に戻さず、全て離してから次の操作を受ける。
- 手のアイコン「移動・閲覧」では、一本指やマウスのドラッグでもPDFを動かせる。書き込みや履歴は増やさない。
- 指で既存の付箋・テキストを触ると選択し、本文をドラッグして移動する。キーボードは「文章編集」から開く。選択枠の操作範囲は指向けに広げる。マウスでは従来の本文クリックで入力、枠で移動を維持する。
- 指で空白をタップした場合、離した時に新規入力を作る。途中で二本指になった場合や、大きく動かした場合は作らない。
- 文章入力中の外側操作では従来どおり確定を試みる。不正な草稿やIME変換中は切り替えを止める。二本指が始まる前に確定済みの文章は、通常どおり自動保存する。

## スマホの配置

幅640px未満でのみ配置を変更する。端末名やブラウザ名では判定しない。

- 編集中のヘッダーを小さくし、ノート名・保存状態・設定・書き出しメニューを置く。初期画面にはOverlay名を残す。
- 道具6種類とUndo / Redoを一列に置く。設定行は初期状態で閉じ、設定アイコンで開閉する。テキスト・付箋を選んだ場合は追加・編集操作を使えるように開く。
- ダウンロードと「※ 重要なノートは定期的に…」は「…」の書き出しメニューへまとめる。注意文は削除しない。
- カードの大きな枠・余白を減らし、操作欄以外の残りの高さをPDFへ使う。PDFのスクロールとピンチはPDF領域だけで処理し、サイト全体のズームを禁止するviewport設定は追加しない。
- 文章入力は画面下の入力欄で行い、文字サイズは最低16pxで表示する。これは入力欄の表示サイズで、PDFへ保存する文字サイズは従来の8〜48。PDF上のプレビューとサイズ指定を維持する。VisualViewportがあればキーボード分の位置・高さを補正する。
- PCでは従来の高さ固定の設定行・倍率・出力・保管案内、PDF上での直接入力を維持する。

## 一覧の長押しと複数選択（2026年10月22日）

- 通常モードでは、項目を約0.6秒長押しすると名前のプレビューが出て、指でフォルダやその子要素の上へ移動できる。離すと確定する。PCのマウスドラッグは従来どおり。
- 長押し前に10pxを超えて指を動かしたらドラッグせず、通常のスクロールに任せる。短いタップはノートを開く・フォルダを開閉する。長押し後の誤クリック・OSの文字選択・native dragとの二重処理を抑止する。
- 閉じたフォルダ上で約600ms待つと展開する。一覧の上下端では自動スクロールする。二本指・touchcancel・ウィンドウのフォーカス喪失は中断し、一覧外や無効な移動先へ離しても保存しない。
- 「選択」を押すとPC・スマホ共通のチェック欄を表示する。ノート名でもチェックを切り替えられ、PDFは開かない。フォルダ名は開閉、フォルダのチェック欄は選択に使う。フォルダを選ぶと閉じた子孫も全て選ぶ。子を外すとその子（フォルダなら中身も）と全ての祖先を解除し、兄弟は維持する。子の個別再選択で親は自動チェックせず、親の再チェックで中身をそろえる。
- 「全選択」は閉じたフォルダ内を含む全項目が対象。「選択解除」で全チェックを外し、「選択終了」で通常操作に戻る。選択中のドラッグは行わず、「移動」から移動先を指定する。キャンセル・失敗では選択を残し、成功時は選択を解除する。
- 親と中の項目を一緒に選んでも親だけを移動し、中身の所属は維持する。既に移動先にある項目はそのまま。同名フォルダ同士を集める操作・循環・全件変更なしは無効。保存時も最新の階層で再検証し、全件を同じトランザクションで更新する。
- 同日の続く指示で「削除」を追加した。確認画面にノート・フォルダ別の件数と階層付きの全対象名を表示する。元に戻せないことを案内し、「削除」で確定、キャンセル・背景・Escapeでは消さない。対象は確認時に固定し、保存時の最新階層に未選択の子がある場合は中止する。全件を同じトランザクションで削除し、失敗時は選択・確認画面・編集内容を残す。開いている対象は保存を待ち、成功時だけ画面と履歴を初期化する。
- PDF・線・文章・履歴の保存形式は変更しない。コピー・手動並び替え・削除後の復元は今回追加しない。

追加したコード：

- `notebookTouchDrag.ts`：長押し・スクロール・中断の切り分け、non-passiveなtouchmoveと誤クリック抑止、指の下の移動先判定。
- `NotebookSidebar.tsx`：長押しと既存の移動処理の接続、展開・自動スクロール・プレビュー、チェック状態と一括移動の進行管理。
- `NotebookTree.tsx`：行の長押し対象・ドロップ範囲、チェック欄と通常タップの切り替え。
- `NotebookMoveDialog.tsx`：一括移動先の選択と無効候補・キャンセル・失敗表示。
- `noteDrag.ts`：親子選択の正規化と一括移動の共通検証。
- `localNotes.ts`：最新の階層を検証し、複数の所属変更を1トランザクションで保存。
- `noteSelection.ts`：親子チェックと、確認済みの選択だけでフォルダも削除できるかの検証。
- `NotebookDeleteDialog.tsx`：固定した対象名・件数・取消不可の確認、キャンセル・失敗表示。
- `localNotes.ts`・`PdfWorkspace.tsx`：全件削除のトランザクション、開始済み自動保存の待機と削除成功後だけの画面初期化。

## コードの役割

| ファイル | 担当 |
|---|---|
| `pageGestures.ts` | 指のID・位置の追跡、二本指への切り替え、拡縮・移動、最後の指が離れるまでのブロック、中断・解除 |
| `PdfPage.tsx` | PDF領域へジェスチャーを接続し、PDF・線・文章を同じ倍率で表示。中間位置のPDF座標をスクロールで維持 |
| `PenLayer.tsx` | 中断通知で未確定の線・消去を破棄。保存座標は0〜1のまま、描画時だけPDFの幅・高さへ変換 |
| `TextLayer.tsx` | 指とマウスの操作を区別し、本文移動・タップ設置・中断を既存の保存・履歴へ接続 |
| `TextBoxEditor.tsx` | 入力・色・サイズ・確定は共用。スマホのキーボード位置の補正と監視解除 |
| `PdfWorkspace.tsx`・`AppHeader.tsx` | 移動・閲覧、設定の開閉、スマホの書き出しメニューとノート名 |
| `globals.css` | 640px未満だけの配置と入力欄。全体テーマは変更しない |

### 線幅の見直し

以前は1×1のSVGに線を置き、`non-scaling-stroke`と表示倍率で幅を補正していた。今回はSVG自体をPDFと同じ幅・高さにし、線幅もPDFの単位で描く。特殊な拡大補正へ依存しない構成にした。保存済みの座標・太さとPDF出力は変更しない。

これは報告された線幅異常の不安定要因を減らす変更であり、原因を実機で特定・再現したという意味ではない。Safari全体を対応完了とは扱わない。

## 確認

自動テストは、ジェスチャーの距離・中間位置・倍率の制限、二本指でのキャンセル、三本目の追加、残った指のブロック、移動・閲覧、付箋・テキスト操作、入力欄のキーボード補正、保存・履歴の維持を確認する。DOMやHooks・captureを代用したテストとCSS指定の確認を含み、実機の操作感の保証ではない。

実機・公開環境での確認は未実施：

- [ ] iPhoneの今回報告されたブラウザで、ペン選択中に二本指で拡縮・移動しても巨大な線や余分な点が残らない。
- [ ] 一本だけ指を残しても描かれず、全て離すと通常の描画に戻る。消しゴム途中からの二本指でも元の線が残る。
- [ ] 付箋・テキストの本文を指で移動でき、文章編集でのみキーボードが開く。移動中の二本指では位置が保存されない。
- [ ] キーボードで完了・キャンセル・色・サイズ・削除を操作できる。横向き・キーボード開閉でも入力内容を失わない。
- [ ] スマホでPDFが広く表示され、設定・書き出し・ページ操作が切れない。ダウンロードと注意文を確認できる。
- [ ] PCの描画・枠移動・直接入力・ホイール倍率、保存・再読込・Undo / Redo・PDF出力が従来どおり動く。

実装時に参照した仕様：[MDNのピンチ操作](https://developer.mozilla.org/en-US/docs/Web/API/Pointer_events/Pinch_zoom_gestures)、[touch-action](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/touch-action)。独自のジェスチャー処理はPDF領域に限定する。
