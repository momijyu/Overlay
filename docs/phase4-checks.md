## 操作と保存

- 「ペンの色」で、これから描く線の色を選ぶ。既存の線を一括で塗り替える機能ではない。
- ペンの太さは「極細・細・標準・太・極太」の5段階スライダーで選ぶ。線幅は1・1.5・2.5・3.5・5、初期値は従来と同じ2.5。変更は次に描く線だけに反映し、既存の線と消しゴムサイズは変えない。
- 「ペン」「消しゴム」を切り替える。消しゴムサイズはスライダーで4〜64の間を1刻みで調整し、現在値を数字で確認できる。初期値は16。PDFの表示倍率に連動して消去範囲の表示も拡大・縮小する。
- サイズ欄のスライダーは選択中の道具のものだけを1つ表示する。ペンと消しゴムを切り替えても、それぞれ直前に選んだサイズを保持する。
- 消しゴムが通過した部分だけを除き、残った線の位置・太さ・色を保持する。
- 消去中はプレビューだけを更新する。指・ペンを離した時に編集結果を渡して自動保存する。何も消していなければ保存しない。
- pointercancelや予期しないPointer Captureの解除では、未確定の描画・消去を取り消す。ページ・ツール・倍率などの変更で描画領域が作り直される場合も、未確定の操作を保存しない。
- 元PDFの文字・図・画像や、既にPDFへ焼き込まれた線は消せない。今回消せるのはOverlayが別データとして保持しているペンの線だけ。
- 自動保存後に開き直しても色・消去結果を復元する。PDFダウンロードも残った線を色付きで出力する。
- Undo / Redoはまだ未実装。確定して自動保存した消去を元に戻す機能はなく、画面にも案内する。

## 変更したファイルと処理の説明

### `types.ts`・`penStyle.ts`・`strokeData.ts`

1本の線に任意の`color`を追加した。新しい線は`#rrggbb`形式の色を持つ。旧データには色を後付けせず、表示・出力時に従来の黒へフォールバックする。座標・太さに加え、保存・読み込み・出力前に色の形式を検証し、不正な値は成功扱いしない。

### `eraseStrokes.ts`

元の点を削るだけでは、点と点の間に消しゴムが当たった場合を扱えない。そのため、隣り合う点を結ぶ線分を計算し、消しゴムと交わる範囲を取り除く。

1. 0〜1の保存座標を表示上の距離へ変換する。縦長・横長ページや倍率の違いを補正する。
2. 消しゴムの移動跡を「両端の円と、その間の長方形」で判定する。イベント間を速く動いても移動途中を対象にする。
3. 線分の始点を0、終点を1とした位置で交差範囲を求め、消していない範囲だけを残す。元の線幅も考慮し、端の丸みで消し跡が埋まらないようにする。
4. 消した範囲の前後を別の線へ分割する。元の色・太さは複製し、位置は0〜1のまま維持する。

入力配列・元PDFは変更しない。何も消えなければ同じ配列を返し、不要な自動保存を避ける。画像化や白塗りはしない。

### `PenLayer.tsx`

ペン入力では描き始めの色・太さを記録する。消しゴム入力では操作中の線を一時的に保持し、移動ごとに部分消去をプレビューする。操作完了時だけ親画面へ結果を渡す。別ポインターや右クリックは編集対象にしない。消しゴムの範囲は表示上の円で示す。

### `PdfPage.tsx`・`PdfWorkspace.tsx`

既存の操作欄へ色選択とペン／消しゴムを追加した。全体テーマ・サイドバー・編集領域のレイアウトは変更しない。`PdfPage.tsx`から色・道具・消しゴム幅を渡し、`PdfWorkspace.tsx`で線の追加と消去後の配列更新を同じ自動保存へ接続する。保存先は従来のIndexedDBのまま。

### `EraserSizeControl.tsx`

ユーザーの追加指示で3段階のサイズ選択をスライダーへ変更した。daisyUIのrangeを使い、サイズの入力と現在値の表示を担当する。選んだ値は`PdfWorkspace.tsx`の既存の状態から消去処理へ渡す。サイズ変更だけではノートの内容を書き換えない。処理中・範囲外・整数以外の値は通知しない。

### `PenWidthControl.tsx`・`penStyle.ts`

ユーザーの追加指示でペンの太さも5段階のスライダーに変更した。`penStyle.ts`で5種類の線幅と表示名を定義し、`PenWidthControl.tsx`でスライダーの位置0〜4を実際の線幅へ変換する。`PdfWorkspace.tsx`の既存のペン幅の状態へ接続し、描画・保存・PDF出力の処理は変えない。サイズ欄は選択中の道具に応じてペン幅か消しゴムサイズのどちらかだけを表示する。道具ごとの値は親画面に残すため、切り替えてもリセットしない。処理中の入力を無効にし、範囲外・整数以外の段階は通知しない。

### `exportAnnotatedPdf.ts`

固定の黒ではなく、各線に記録された色でPDFへ描画する。部分消去後は分割された線だけを描くため、切れ目が再接続されない。元PDFを上書きせず、新しいPDFとして出力する。
